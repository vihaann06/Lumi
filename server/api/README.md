# API Routes

This directory contains backend API route handlers.

## Structure

- `/api/documents` - Document management endpoints
- `/api/folders` - Folder management endpoints
- `/api/ai` - AI service endpoints (explanations, summaries, chat)
- `/api/highlights` - Highlight management endpoints
- `/api/vector` - Vector search endpoints
- `/api/ingestion` - Document ingestion endpoints

## Future Endpoints

- `POST /api/documents/upload` - Upload document
- `GET /api/documents/:id` - Get document
- `POST /api/ai/explain` - Get AI explanation
- `POST /api/ai/chat` - Chat with AI agent
- `GET /api/vector/search` - Vector similarity search
